What main.py does

It runs each script as its own process, in this order: data_prep, descriptive, garch_models, evt, backtest, es.
If a step fails, it stops and prints the exact command to resume from that step.
It checks that the required packages are installed before starting.
Figures are only saved by default, so nothing blocks waiting on a plot window. Use --show if you want them to open.
Use --only and --skip to run part of the pipeline, for example python main.py --only evt backtest es.
